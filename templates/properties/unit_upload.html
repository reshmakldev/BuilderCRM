Excel Format Instructions:

Please ensure your Excel file has the following columns (in order):

  1. Unit Number (Required, e.g., A-101)
  2. Tower (Optional, e.g., Tower 1)
  3. Floor (Optional, Number 1-Total Floors)
  4. Floor Plan Type (Optional, e.g., A, B)
  5. Unit Type (Optional, e.g., 2BHK)
  6. Size (Optional, Sq. Ft.)
  7. Price (Optional, Amount)
  8. Status (Optional, Available/Blocked/Sold)

First row is treated as header and skipped.
